# Product Images

Place product images here. Each product expects **3 image files**:

    {product-slug}-1.jpg   (primary)
    {product-slug}-2.jpg
    {product-slug}-3.jpg

## Image specifications

- **Format:** JPG (or replace the `.jpg` extension in the seed and re-run)
- **Dimensions:** 1200 × 1600 px (portrait, 3:4 aspect ratio)
- **File size:** under 300 KB each
- **Background:** plain (light grey, off-white, or studio background)
